# plan2csg — 平面图一比一复现 CSG 白盒关卡(管线使用指南 + 标准指令)

> 2026-07-14 建成,验收基准 IoU ≥ 0.98。方法复盘见本文末尾;标准指令可直接复制给 Fable 5。

## 一、管线概览(四步,全部可重跑)

```
关卡/<平面图>.png
  → ① plan_trace.gd      描迹:像素→轮廓多边形(阈值/图标重分类/细缝过滤/DP简化) → 关卡/level_trace.json
  → ② plan_build_csg.gd  生成:轮廓→CSG 场景(.tscn,真实节点可编辑,零布尔/零运行时脚本)
  → ③ capture_topdown    俯拍:正交垂直俯拍 + bounds sidecar(非 headless)
  → ④ plan_overlay.gd    比对:描迹栅格化 vs 俯拍 → IoU 数值 + 红绿重叠图
```

```bat
:: G = Godot 4.6 可执行文件
%G% --headless --path . --script res://tools/plan2csg/plan_trace.gd
%G% --headless --path . --script res://tools/plan2csg/plan_build_csg.gd
%G% --path . --resolution 1920x1080 res://tools/capture_topdown.tscn
%G% --headless --path . --script res://tools/plan2csg/plan_overlay.gd
```

输出:场景 `scenes/levels/level_03_csg.tscn`;比对材料在 `tools/_capture/`(不入库):
`plan_overlay.png`(红=仅原图缺失/绿=仅引擎多出/白=重合)、`plan_contours.png`(描迹叠加原图)、俯拍与特写。

特写检查(墙脚衔接/任意细节):
`%G% --path . res://tools/capture_topdown.tscn -- --tilt 58 --focus <x> <z> --size 30 --out res://tools/_capture/seam_check.png`

## 二、前置条件与配置

1. **参考图必须是工作区里的文件**(如 `关卡/LevelClean.png`),聊天粘贴的图无法进入像素管线;
2. 图面约定:白/浅色=可走区域,黑=背景;图标尽量清空(清空版精度最高);
3. `plan_config.json` 关键项:`image`(图路径)、`world_width`(世界宽度,定比例尺)、`entrance_px`/`spawn_px`(入口/出生点像素坐标)、`lum_min`(地面亮度阈值)、`hole_min_thickness_px`(细缝过滤)、`fill/keep_holes_at_px`(洞分类人工覆盖)。

## 三、标准指令(复制即用)

### A. 全新平面图 → 复现关卡

```
【AI 关卡复现指令】
参考图:关卡/<文件名>.png(白色=可走区域,黑色=背景;忽略图内一切图标/文字/参考网格,
仅保留 <位置描述> 的入口传送门作为入口标识与出生点)。
用 tools/plan2csg 管线将平面图一比一复现为 CSG 白盒关卡(只含地面+墙壁+洞体块的基础结构)。

硬性要求:
1. 位图直驱:轮廓必须从图像像素程序化描迹,禁止目视估算坐标、禁止手写矩形近似;
2. 重叠对比法:每轮改动后俯拍并与参考图栅格化重叠比对,报告 IoU 与红绿重叠图;
   IoU ≥ 0.98 达标;刻意修正的绘图伪影(细缝/图标残留)在报告中单列解释;
3. 产出为保存成 .tscn 的真实 CSG 节点场景:编辑器可手工编辑,游戏运行时零生成逻辑,零布尔运算;
4. 墙体一体化连续挤出、转角圆滑,无缝隙无凸刺;地板完整垫在墙体下方,与墙之间不得有空洞;
   洞=实心岩体;全部带碰撞(layer 4);
5. 出生点设在入口标识处并更新 play 场景;headless 启动 0 报错;
6. 发现缺陷先做控制实验定位根因(隐藏图层对照拍摄/局部放大裁切/轮廓数据打点),
   再从生成规则层面修复,不做逐处手补。

交付:场景文件路径、最终 IoU、tools/_capture/ 下的重叠图+俯拍+特写、假设与偏差清单。
```

### B. 对现有关卡微调迭代

```
参考图不变(tools/plan2csg/plan_config.json 所指)。对 level_03_csg 做以下调整:<改动点>。
要求:改完重跑 描迹→生成→俯拍→重叠比对 全链,报告 IoU 变化与重叠图;
若引入新偏差,先控制实验定位根因再修;play 场景 headless 启动 0 报错。
```

### C. 衔接细节检查

```
用 capture_topdown 的 --tilt/--focus/--size 拍 <位置/世界坐标> 的斜视特写,
检查 <墙脚与地板衔接/岩体贴合/转角平滑>,发现问题从生成规则层修复并复拍验证。
```

## 四、方法复盘(为什么第一版不行,后来为什么行)

| | 第一阶段(不达标) | 第三阶段(达标) |
|---|---|---|
| 输入 | AI 目视读图,凭感知估坐标 | 图像文件进工作区,像素程序化描迹 |
| 表达 | 手写轴对齐矩形表(有机轮廓无法表达) | 真实轮廓多边形(DP 简化保留曲线) |
| 验收 | 再次目视对比("看起来像不像") | IoU 量化指标 + 红绿重叠图 |
| 排障 | 凭推测改参数 | 控制实验归因(隐藏图层 A/B、放大裁切、数据打点) |
| 修复 | 逐处补丁 | 生成规则层根治(重分类/形态学/构造性保证) |
| 复用 | 一次性人工劳动 | 四步管线,换图即重跑 |

核心转变一句话:**从"让 AI 感知并复述"转为"让数据直接驱动几何,用数值度量代替目测验收"**。
IoU 轨迹:0.74(布尔挖洞失效)→ 0.92(岩体方案)→ 0.95(细缝过滤)→ 0.989(路径挤出墙)→ 0.98~0.99(贴合收口,余量为刻意修正项)。

踩坑备忘(规则已固化进工具,换图一般无需再处理):
- 彩色图标会在地面边缘咬缺口 → 色度重分类(继承最近非彩色类别);
- 描边与地面填充间的内阴影线会形成贴边细缝伪洞 → 细缝过滤(面积/最大边长);
- CSG 布尔减法渲染不可靠 → 洞一律实心岩体,全场景零布尔;
- 独立墙段在凹角互相穿插 → offset_polygon 圆角路径连续挤出 + 闭运算;
- 地板与墙留缝 → 地板改由墙中线再外扩生成(构造性保证垫到墙下)。
