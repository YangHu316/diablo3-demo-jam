## 四·八、v5:美术墙面首尾无缝 + 装饰落地 + 点地波纹(第三轮反馈驱动)

用户反馈:v4 对齐的只是"空气墙"(CSG 碰撞),**美术墙体模型**之间仍有错缝/漂移;地面装饰有埋入地下的;另需鼠标点地白色波纹反馈。三项修复与根因:

1. **墙模型无缝——根因是网格原点** —— 高倍正交放大(26m 视野)锁定病灶:同一条链上的墙件呈"整体平移"式错位,并非角度误差。量化资产目录后发现 **Wall_01/Wall_01_Alt 的网格原点在模型一端而非中心**(catalog `center_xz=[2.47,0.06]`),此前所有"按中点摆放"的代码全部隐性偏移半件墙——v2~v4 反复修缝修不净的总根因。修法:
   - 逐边按可走性采样定内外向,整条边外移 `HALF_T=0.22`(内侧砖面与可走边界齐平);
   - 相邻外移边求交得**共享斜接角点**(miter joint),每段在两个角点间等分 `n=round(len/5.24)` 件、缩放 ×1.005 咬合;
   - 摆放时以 `位置 = 中点 − yaw基 × (center_xz ⊙ 缩放)` 补偿原点偏移——一行公式终结三轮缝隙;
   - 转角 >10° 处放 0.72 倍圆柱包角,直线段不放(消除旧版"糖葫芦"感)。
   证据:v5_wall_zoom1/2.png(高倍)+ v5_full.png(全图)——墙链首尾相接、砖面朝内、无外漂无内凸。
2. **装饰落地** —— 资产目录补测每件 `min_y`(网格最低点),统一 `_ground_y = DECOR_TOP − min_y×缩放` 公式摆放:烛台/瓦砾/骨堆/木箱全部立于地砖面(+0.14m)之上。证据:v5_beauty.png(50° 斜视)。
3. **点地白波纹** —— `player.gd`(⚠ 主线共享文件,L2 同步生效)`_spawn_click_indicator` 重写:点敌保留单圈红环;点地改为 3 圈白环错峰扩散(延迟 0/0.12/0.24s、终缩放 1.5/1.25/1.0、0.45s 淡出),环面抬高 +0.22m 保证浮在美术地砖之上。

回归:校验 8/8 通过、播放场景 25s 实跑 0 错误。截图归档:截图/v5_*.png。

## 四·九、v6:主题装饰群填充 + 多智能体审计闭环(第四轮反馈驱动)

用户诉求:场景太空旷,增加装饰;并点名「装饰半埋入地下——注意坐标原点问题」。本轮采用「编目先行 → 模板化群落 → 并行多智能体审计 → 数据定位修复」流程:

1. **编目先行,系统性关死原点问题** —— 资产目录从 41 条扩到 **112 条**(所有拟用资产逐一实测 size/min_y/center_xz)。实测证明用户直觉正确:挂幅原点在**顶端**(min_y=-4.21)、巨骨原点悬在半空(Bone_Skull_02 min_y=-3.97)、碎陶原点偏上(+0.04)——不经编目直摆必然半埋/悬浮。全部摆放统一走 `_ground_y = 落地面 − min_y×缩放`;未编目资产触发 printerr 警告(本轮 0 条)。
2. **九类主题群落模板** —— 王座间(骸骨王座+双吊锅)、祭坛(+头骨+地毯)、墓地(石棺基座+符文墓碑)、白骨堆(缩放巨骨件)、刑房(铁笼/枷锁/铁处女)、储物角、书房残迹、石泉、篝火营地;外加靠墙雕像/残柱/石灯/地毯单件、墙面挂幅(顶端锚定 3.35m、垂长 2.3m)与细碎遗骸散布,共 **~200 件**。锚点采样带净空区间约束、群落间距 7m、避让区(入口/地标/水晶簇)外扩 2m;背墙类群落按最近墙法线自动朝向场内。
3. **并行审计(5 智能体,30 条发现)** —— 落地/朝向/密度/墙体回归四个图像镜头 + 一个对抗性代码审计,交叉复核 5 张正交截图与场景节点数据。关键战果:
   - **地砖原点缺陷(代码审计发现,数据证实)**:地砖网格原点也在角部(center_xz=[2.5,2.5]),v5 及之前所有版本的地砖被随机 90° 旋转甩进相邻格——之前看到的"墙外淡色方块"和"光滑无缝地面"其实是**砖被甩飞后裸露的 CSG 白盒地面**。修复:与墙同款的原点反向补偿 + 各变体厚度差异统一顶面对齐(TILE_TOP=0.13)+ 半砖/四分之一砖两级弧缘填充(全部改用带纹理变体),地砖 323 → **704 块**,首次实现全场石板铺面。
   - **火把朝向翻转(落地镜头发现)**:逐边单点采样在薄岩体上会"隔洞采到对面地板"致朝向反转,两处火把挂进了岩体背面。修复:两侧多距离投票定向 + 挂点"内可走/外不可走"双检(火把与挂幅同款)。
   - **审计误报也有价值**:「石灯悬浮虚空」经数据核对为正常落地(黑色岩顶被误读为虚空)——图像审计需与场景 transform 交叉验证才可信。
   - 其余修复:巨颅避让区坐标写串(z/yaw 误读)、群落成员按编目 footprint 计算所需净空(防巨骨/断柱穿墙)、散布加入避让区检查、斜倚姿态资产(Coffin_01/Bench_01)换平放件、模板成员间距按实测尺寸拉开、三大空旷厅手摆视觉锚点(入口雕像仪仗/枢纽残柱半圈/西北石台祭件)。
4. **回归**:校验 8/8、启动 25s 0 错误、墙体回归逐像素对比无退化(全图仅 157 像素差异且均为装饰加法)。截图归档:v63_full / v63_tiles_only(隐藏白盒的纯美术地砖证据)/ v6_close_* / diag_*。

### v7.1:透视首版返修(用户实测:模型破碎/原地抽搐/蓝色常驻)

- **根因**:首版用 `depth_test_inverted` 的 material_overlay,无法区分「被墙挡」和「被自己身体挡」——手臂在躯干后、护甲片互叠处全部触发剪影,随动画逐帧变化 → 浑身蓝斑闪烁,视觉上即"破碎+抽搐+常驻"。对照实验(DH_NO_XRAY=1 关闭后角色渲染完全正常)锁定责任。
- **修复**:改用 Godot 4.4+ **模板缓冲 STENCIL_MODE_XRAY 预设**(ClassDB 探针确认 4.6.2 可用):本体材质渲染处写 stencil 标记,剪影 pass 只在「无标记且被深度遮挡」处上色 → 自遮挡天然免疫。逐网格复制材质实例再开启,不污染与敌人共享的 FBX 原材质。
- **连带发现并修复**:透视剪影把「角色双脚常年埋在美术地砖里 13cm」照了出来(碰撞面=隐藏 CSG 顶面 y=0,砖面在 0.13)——`TILE_TOP 0.13→0.02`、`DECOR_TOP 0.14→0.035` 整体压低重建,点地波纹抬高量 0.22→0.06 同步回调。
- 证据:crop_final_visible.png(可见时零蓝斑、脚踩砖面)、crop_stencil_xray.png(隔墙全身剪影+露头正常)。校验 8/8、启动 0 错误。
